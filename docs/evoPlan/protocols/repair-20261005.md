# Walker failure-rich predictor and probe repair

User authorization: implement the recommendation following the completed divergence diagnostic. This explicitly extends the earlier frozen-model scope with a bounded predictor/probe repair experiment. Historical studies and artifacts remain unchanged. No encoder adaptation, new controller evolution, second environment, or new simulator interaction is included.

## Question and split

Can local prediction and physical readout repair improve failure-onset detection while retaining ordinary-motion accuracy, and does the development-selected repair nominate a better real controller from the existing fixed pool?

Use all 89 candidate trajectories on the 32 real-selection and 64 development-check source episodes already exposed by candidate-quality and divergence studies. Sort the 96 unique source episode keys by SHA256 of `20261601:<key>` and assign four consecutive groups of 24 to probe fitting, predictor fitting, development, and audit. Save exact identities and hashes before fitting. All candidate siblings stay together. This audit is held out from this fitting/selection procedure but is reused development evidence, never untouched confirmation. Existing final/confirmation banks are not queried.

## Fixed intervention

Three fitting seeds: 20261611, 20261612, 20261613. Restart each fit from the original pinned model/probe. Keep image encoder, projector, action encoder, all buffers/running statistics, and all normalizers bitwise frozen. Fit only predictor and prediction projector; retain eval mode while enabling their gradients. Cache detached real target latents and exact three-real-frame/past-action contexts. No future frame enters a predictor input. The full 12-position action encoder buffer has later positions zeroed.

Fit the existing probe network, with identical capacity and frozen normalization, on its separate episode group. Both fitting datasets include endpoints through the first failure-containing block, never later states. Half of each batch samples the last two endpoints through a failure-containing block; half samples the remaining eligible ordinary endpoints. This is retrospective failure-rich supervision, not a prospective acquisition method.

Each seed receives exactly 1,000 probe and 1,000 predictor optimizer steps, batch 256, AdamW weight decay 0.0001, gradient norm clip 1. Probe LR 0.0001; predictor LR 0.00001. Probe loss is physical MSE scaled by (0.2 m, 0.5 rad, 5 m/s). Predictor loss is latent MSE plus 0.1 times that physical MSE through the original frozen probe. The probe-only and dynamics-only controls separate the interventions. No early stopping, hyperparameter sweep, seed selection, or outcome-dependent extension. Save the final checkpoints from every seed.

## Comparison and gate

Evaluate baseline, probe-only, dynamics-only, and combined repairs, with one-step real-history predictions and ten-block real-action-tape rollouts. Baseline latents/readouts reuse verified divergence archives. The repaired probe also reads real image latents to isolate readout quality. Report first-failure-containing unsafe-endpoint detection, false alarms at still-healthy endpoints strictly before dense failure (including healthy trajectories), height/pitch/speed MAE on the same healthy endpoints, and signed height bias at the event. The first-containing endpoint may follow failure by up to 72 ms. These are not root-time advance-warning rates.

The development gate, on seed-averaged one-step counts, requires at least +10 percentage points endpoint detection, no more than +2 points healthy-endpoint false alarms, and each height/pitch/speed healthy MAE at most 1.25 times baseline. Among passing arms choose greatest detection, then lowest false-alarm rate, then fixed arm order (probe, dynamics, combined). Freeze this choice before inspecting repaired audit results. Report all seeds and arms; seed repeats are not new episodes. Episode-cluster bootstrap (2,000 draws, seed 20261609) is conditional on this pool and split; point gates are engineering criteria, not significance claims.

If no repair passes development, report the negative result and do not perform new closed-loop controller nominations. If one passes, run its closed-loop imagination on development episodes only, pooling the three seeds; baseline reuses archived closed-loop predictions. Select a nonbaseline candidate only if its imagined failure rate is strictly lower than the baseline controller's and predicted progress retains at least 90% of baseline. Break ties by greater progress, then candidate index; otherwise fall back to baseline. Save both nominations before opening the numerical audit summaries. Simulator audit outcomes are already archived because actual controllers and encoders are unchanged. Report paired real failure differences and progress, including fallback. Audit gate success is additionally required before recommending any promotion or fresh confirmation. No promotion is automatic.
