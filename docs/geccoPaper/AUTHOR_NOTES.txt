GECCO short/poster draft, 5 October 2026

Open main.pdf. The anonymous ACM sigconf draft is four pages including references.
It contains four figures (a saved-state image sequence, a protocol diagram, the
full actual-failure grid, and the two primary contrasts) and two tables (method
outcomes and charged main-study compute). Figure PDFs are vector graphics except
for the authentic simulator images; PNG versions and the three separate images
are also included. Every figure has an ACM accessibility description.

Build

  From repository root: uv run python experiments/helpers/geccoPaper.py
  To rerender saved pictures: add --render to that Python command.
The document builds from committed assets without the private run data. Rebuilding
numeric figures uses the committed Stage 5 analysis. Rerendering the pictures also
requires the archived run directory and the existing MuJoCo environment. It
restores recorded qpos/qvel and renders three images, with zero simulator steps
and zero model queries. Figure provenance JSON records the source hashes and
example selection. The archived dense_first_step is zero-based: index 61 means
completed step 62, at 0.496 seconds.

Scientific interpretation
The primary result is a real-minus-imagined failure-gap contrast, not false-safe
acceptance conditional on a safety filter. The noise scale is fixed per latent
coordinate from development residuals, not state-dependent uncertainty. The
penalty adapts observed branch-return extrema, not exact state-value extrema or
a proven minmax bound. The combined method mitigates search-induced harm but
remains worse than the starting controller. The paper preserves failed historical
gates, source-distribution conditioning, unequal model sampling, post-failure
progress, and incomplete upstream cost accounting. No new scientific queries
were performed to write the paper. Source analysis and locked experiments remain
unchanged.
