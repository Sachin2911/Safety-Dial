# Preserved ManiGuard study audit sources

These are byte-identical text copies of the analysis programs saved with the completed
196-episode study. Identical program contents are stored once. The
[audit source manifest](../ManiGuard%20fruits%20audit%20source%20manifest.json)
maps every original result-directory source path to its repository copy and SHA-256.

The `.py.txt` files are provenance artifacts, not generic launch commands. They retain
the original `/workspace/Safety-Dial` paths and exclusive output checks to protect
recorded evidence. Do not rerun them over completed outputs. For new experiments use
the [study commands](../../../../configs/maniguard/README.md) and new output directories.
The final requirements source records local verification; GitHub publication verification
is recorded separately after the results commit is pushed.
