# Historical figure dependencies

These ten helpers support the retained October manuscript figure scripts. They were
moved from the root `experiments/` during the 3 November consolidation. The live
figure scripts now import them from this directory; the original locations and
hashes are in `docs/records/consolidation-20261103.json`.

Several figure generators still need historical `outputs/` inputs that Sachin
previously requested deleted. Their code and the existing manuscript figures remain,
but regenerating those figures requires recovering the missing inputs from an
independent copy. This cleanup did not run or recreate any experiment.
