# Machine-readable experiment evidence

[Principia](../../principia.pdf) is the human-readable experiment record. Receipts here
retain original names and bytes, including failed engineering attempts and superseded
freezes. Number prefixes map to the numbered task accounts T01 to T19.

Baseline task 1 uses prefixes `01`, `01b` and `01c` for instances B, C and D. Instance B's
excluded seed zero remains under `excluded-instance-B/`. Task 5 executed
`05-adapter-plan-v4.json`; earlier versions are historical evidence.

Preservation receipts identify private datasets, revisions and verification. Frozen
source snapshots, environment text files, patches and figures remain evidence too.
Do not edit them to fit a later summary. Source paths may name documents removed from
the working tree; restore those bytes from the
[document bundle](../../archive/20261029/README.md) when checking historical manifests.

The current manuscript's evidence manifest is an original snapshot of its inputs.
Principia's [source inventory](../../docs/research/principia-evidence.json) records
its own input hashes. Both can be resolved against the retained tree and bundle.
