# Interpretation of the first matched-budget development pilot

The pipeline completed 20 searches, each with exactly 189,760 predictor rows including nominee audits. All 635 query archives, 110 executable-source snapshots, 20 simulator selection decisions, and the statistical analysis passed independent reconciliation. Runtime was 549.805 seconds, with 4,241,280 predictor rows and 134,400 new simulator steps. Reusing identical policies reduced simulator use below the declared 457,600-step cap.

Every simulator-verified choice retained the starting controller. That controller failed on 6/32 selection episodes (18.75%); no shortlisted new controller achieved a strictly lower selection failure rate. Some tied it, and the predeclared rule retained the baseline on ties. On the separate, reused evaluation subset, the baseline failed on 4/64 episodes (6.25%). The difference between these small banks illustrates why selection and evaluation outcomes must stay separate and why the larger historical baseline failure rate must not be replaced by this subset result.

For the noisy adaptive-penalty arm, imagined selection yielded 14.84375% mean final failure over two search seeds. Simulator verification yielded 6.25% by retaining the baseline. The paired difference is -8.59375 percentage points with a 97.5% interval [-23.4375, +3.125]; it includes zero. Mean progress retention versus imagined selection is 99.588%, with a separate 95% interval [97.370%, 102.015%]. Against the starting controller, the verified result is exactly the same policy, with zero empirical difference. This is not a learned-policy improvement or a demonstrated population safety gain.

All three fixed penalties tied after simulator verification because all selected the same baseline. The predeclared smallest-penalty tie break selects lambda=0.5. This is a procedural choice, not evidence that 0.5 is superior; its imagined-selected result was actually worse than the stronger fixed penalties on this small development subset. Keep this tie and all negative results visible in any later paper.

The next research milestone remains a separately locked, fresh-bank study with more search seeds, followed by cross-environment and independent-world-model replication. Before allocating that larger budget, review whether the goal is to confirm the fallback mechanism or to produce controllers that improve on the baseline. This pilot supports further investigation of candidate quality and model error; it does not justify claiming that noise and penalties solved the control problem. No fresh confirmation, Hopper run, or independent-world-model replication has run in this implementation tranche.
